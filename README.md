# CreatorsHub — мокап мини-аппа

Интерактивный концепт мини-аппа CreatorsHub в Telegram и веб-версии кабинета креатора.

- `index.html` + `img/` — версия для хостинга (GitHub Pages), картинки отдельно — быстро грузится.
- `standalone.html` — тот же мокап одним файлом, скрины встроены. Удобно переслать и открыть локально.
